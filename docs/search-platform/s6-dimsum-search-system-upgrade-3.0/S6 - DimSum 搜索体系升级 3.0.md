# S6 \- DimSum 搜索体系升级 3\.0

# **语料分层、词条身份信息、多媒体结果与分享卡片**

- 适用范围：Search Web、Search App、Admin后台、语料入库流程、卡片分享工具、SEO落地页

- 实施设计与接口索引：[README.md](README.md)

# **项目背景**

DimSum以粤语口语内容为核心，同时逐步接收地方志、建筑资料、习俗记载、字典词条和历史文献等文化知识。两类内容若共用同一搜索范围，用户难以区分结果属性，推荐内容也容易显得发散。

本次升级在既有“精准结果—相关结果—推荐结果”、词条身份信息、Unique ID与分享卡片能力上，新增内容属性分层、视频结果交互、AI辅助二级分类及轻量审核路由。即：

1. 口语语料与文化知识的顶层分层。

2. 文本、音频、视频、图片的结果类型分支。

3. 原文、来源、AI派生内容与分类状态的可追溯管理。

4. 保留并强化每个词条的身份信息、Unique ID、来源、分类、标签及分享卡片能力。

# **项目目标**

|**目标类型**|**目标**|
|---|---|
|业务目标|建立可检索、可展示、可分享、可追溯的词条身份数据底座；保持平台粤语核心定位，同时承载合规文化知识。|
|搜索目标|口语语料与文化知识分开检索；支持文本、音频、视频、图片等不同结果形态。|
|运营目标|Agent辅助补齐二级分类；只在需要时通过现有标注小程序推送人工审核，不新增独立审核后台。|
|用户目标|用户能了解内容、读音、来源、分类和唯一标识，并能复制链接或生成分享卡片。|

# **核心概念**

|**概念**|**定义**|
|---|---|
|词条/内容单元（Entry）|可被搜索、展示、分享、推荐的基础内容对象，可为词、短语、句子、正文片段、音视频切片或图片资料。|
|Unique ID / entry\_id|每个词条或内容单元的全局唯一标识，用于展示、复制、链接解析、维护、埋点和追溯。|
|口语语料|以粤语实际表达为核心，例如影视对白、访谈转写、录音、粤语剧本、俗语和习语。|
|文化知识<br>|与岭南/粤语相关的书面知识，例如广州话正音字典、地方志、建筑资料、习俗记载和历史文献。|
|Source corpus|内容所属语料库或资料集名称，例如广州话正音字典、十三行资料集。|
|派生内容|基于原文生成或加工的内容，例如粤语口语版、粤拼或视频转写；必须可回溯到原始内容。|
|推荐阅读|探索性推荐内容，不是搜索词的直接匹配结果。|

- 默认搜索不要求用户先选择内容属性，精准结果按现有全库匹配和排序返回。

- 调用方明确选择“口语语料”后，精准、相关和推荐结果均只从口语范围返回。

- 显式属性过滤时，当前范围无结果不得静默混入另一属性内容；前端选择器和切换入口列入后续交互需求。

# 后端与入库设计

## 入库流程

保持“Agent初判—仅在需要时推送标注小程序—标注员Review—结果回写”的轻量流程。不新增独立人工审核后台，也不要求一线人员处理复杂论文式分类编码。前台仅展示可读的内容类别、分类和标签。

📌本项目不要求标注员掌握完整学术分类体系。复杂分类逻辑、跨类判断和规则匹配由Agent及平台分类配置承担；标注员仅在收到任务时，根据内容、来源和可选分类完成确认、修改或暂不分类。标注任务页面应以“内容判断”而非“分类规则学习”为中心，避免要求标注员理解论文式分类编码、复杂层级关系或技术处理过程。

## 词条身份与入库字段

### 字段使用原则

- 每个词条仅有一个entry\_id；内容属性、分类、标签和媒体资源可更新，但不得改变entry\_id。

- source\_corpus说明内容来自哪个资料集；original\_text说明原始内容，两者不可混用。

- 原文、原始音视频和原始图片不得被AI生成内容覆盖；派生内容通过parent\_id关联原始内容。

- 贡献者信息仅在授权时公开展示。

- 草稿、待核、不可公开或受限内容，不得生成公开分享卡片或公开分享链接。禁训仅控制训练用途，不单独阻止公开和分享。

## AI二级分类预标注与标注小程序路由规则 @RAiN

Agent的目标是辅助分类，不直接决定正式分类。系统允许Agent提出一个二级分类候选，但必须保留原文依据和状态；未经标注员确认的建议不得作为训练标签或精准筛选唯一条件。

### 适用范围

- 内容已有一级分类但缺少二级分类。

- 标题、正文、摘要、转写或已有标签中有足够判断信息。

- 来源语料集、内容属性和原文位置已填写，可回溯。

以下情况不自动补分类：

- 原文严重残缺或OCR错误明显；

- 来源/内容属性/版权未确认；

- 内容明显跨多个二级分类且无法判断核心主题；

- 内容不适用现有二级分类体系。

### Agent输出要求

|**输出项**|**说明**|
|---|---|
|建议二级分类|仅输出一个最可能的候选分类。|
|分类依据|返回标题关键词、正文片段或已有标签。|
|分类状态|待抽检 / 待标注员审核 / 留空。|
|简短说明|一句话说明判断逻辑，供标注员快速Review。|

#### 分流与标注小程序通知

|**情况**|**Agent处理**|**状态**|**后续动作**|
|---|---|---|---|
|正文或标题有明确依据，仅对应一个分类|填写候选分类和依据|待抽检|自动入库，可用于普通相关推荐；按比例抽检，不逐条通知。|
|多个合理分类、内容跨主题、依据不足或规则冲突|填写最可能候选和依据|待标注员审核|通过现有标注小程序向标注员推送审核通知。|
|无法判断或内容不适用|不填二级分类|留空|标记待补/不适用，不推送无意义审核任务。|
|原始资料已给出分类|不调用Agent补分类|已确认|直接采用，来源标记source\_provided。|
|标注员完成Review|保留Agent依据与最终结果|已确认|回写最终分类，来源标记reviewer\_confirmed。|

#### 使用限制与抽检

- 待抽检的Agent建议可用于普通相关推荐和运营整理，但不得直接进入训练集。

- 待标注员审核的建议不得用于公开二级分类、精准筛选或训练标签。

- 留空不是错误状态；资料不足时优先留空。

- 首期按来源语料集和内容类型，对待抽检内容随机抽查10%–20%；错误率高的内容类型提高抽检比例或全部改为“待标注员审核”。

#### 公开前台展示规则

- 公开前台不展示“AI建议”“AI置信度”“AI分类依据”等内部处理信息。

- 已确认的Agent建议或经标注员Review后的分类，统一展示：分类状态：已审核整理。

- 原始资料直接提供的分类，展示：分类状态：原始资料整理。

- 待标注员审核的二级分类不在公开前台、公开分享卡片或SEO落地页展示；留空时直接隐藏二级分类字段。

Agent记录、分类依据、标注小程序通知和Review结果仅在系统数据记录与标注小程序中保留。

#### 双版本内容关联

|**首次入库类型**|**默认处理**|**对应版本策略**|**搜索侧行为**|
|---|---|---|---|
|文化知识|保留书面原文、来源、正文位置、版权及训练权限。|内容适合口语化时，可生成粤语口语版\+粤拼，作为派生内容并审核。|切到口语语料时，仅展示审核通过的粤语派生内容。|
|口语语料|保留粤语原文/转写、粤拼、音频或视频。|不主动批量生成书面文化知识版。|切到文化知识时，优先检索广州话正音字典及其他独立入库的文化资料。|

## 媒体筛选器（方案B已确认）

媒体筛选器只影响二级相关结果；一级精准结果和三级推荐结果保持稳定。

|**方案**|**作用范围**|**优点**|**风险**|
|---|---|---|---|

- 禁止白屏、无限加载或无失败反馈。

## 分享卡片默认内容

- DimSum品牌标识。

- 词条内容/标题。

- 读音、粤拼或简短释义。

- 来源语料集。

- 可读的一级/二级分类（仅已确认分类）。

- 关键标签：优先精准标签，其次关联标签。

- Unique ID。

- 可解析的固定分享链接或二维码。

## 分享规则

- 分享卡片以entry\_id作为唯一生成依据；卡片链接、二维码、下载文件名和埋点均关联该ID。

- 仅已上线且可公开内容生成公开卡片。

- 草稿、待核、不可公开或待标注员审核分类的内容不得生成公开分享卡片。禁训内容在其他公开条件满足时允许分享。

- 分享链接必须直达词条详情或可解析搜索落地页，不得只跳首页。

# 验收标准

## 数据与入库

- 每个正式、可检索内容具备稳定唯一entry\_id。

- 正式内容必须填写内容属性、来源语料集、来源位置、媒体类型、权利状态、训练权限和整体审核状态。

- 派生内容必须填写parent\_id、派生类型、生成方式和审核状态。

- Agent建议需保留分类依据和状态；待标注员审核内容必须成功推送至标注小程序。

- 未确认Agent分类不得作为训练标签、唯一精准筛选条件或公开二级分类。

## 搜索与前台

- 默认未过滤搜索按现有全库规则返回；显式传入口语语料/文化知识后，精准、相关、推荐结果不得跨属性补位。

- 精准结果完整展示身份信息、来源、分类、标签、Unique ID和可用操作。

- 公开前台不展示AI建议、AI置信度和AI分类依据。

- 已确认分类展示“已审核整理”；原始资料分类展示“原始资料整理”；待审核或留空分类不公开展示。

- 推荐区显示“以下为推荐阅读，非直接匹配”。

## 多媒体与分享

- 视频卡片具备关键帧、时长和适用时的视频优先标识；列表不预加载视频流。

- Web视频使用右侧播放面板，App视频使用底部Sheet，均可查看时间码转写。

- 视频失败有可感知降级提示，并在资源存在时提供文本/音频入口。

- 已上线且可公开词条可生成分享卡片；Web居中弹窗，App底部Sheet。

- 分享卡片包含词条、来源、可读分类、关键标签、截断Unique ID及可解析链接/二维码。

- 分享链接、二维码、下载文件和分享埋点均关联entry\_id。
