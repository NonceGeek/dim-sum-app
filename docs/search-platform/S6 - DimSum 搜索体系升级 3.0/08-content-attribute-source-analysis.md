## 一、质量结论

Production 当前共有 50,994 条 Entry、29 个来源，全部能关联 `cantonese_categories`，来源配置缺失数为 0。

来源名称只能用来定位，最终判断同时核对了：

- 来源说明；
- 每来源数量和加工状态；
- 每来源固定样本；
- `note/structured_note` 实际正文；
- 当前一级、二级分类；
- PRD 对 oral/cultural_knowledge 的定义。

媒体类型不作为属性判断规则。音频、视频或图片只用于理解内容形态。

## 四、数据质量风险

| 发现 | 风险 | 严重度 | 处理 |
|---|---|---|---|
| 三个来源在一个 Entry 混合两个属性 | 自动二选一会让另一属性检索丢失内容 | 高 | 保留 unclassified |
| `txyl1` 全部 draft 且来源非公开 | 属性不能替代公开权限或加工状态 | 高 | 只写 oral；搜索范围继续沿用现状 |
| 测试来源和测试文本仍在主表 | 默认搜索可能命中测试内容 | 中 | 本期不借属性字段隐藏，另做来源治理 |
| 媒体与内容属性并非一一对应 | 按 audio/video 自动判断会误标知识讲解 | 高 | 映射不使用媒体硬规则 |
