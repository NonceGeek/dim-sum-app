二、系统节点细节说明（各节点系统处理方式）
Fynn：系统处理
  • 校验入库字段、权利与公开状态
  • 调用 Agent 并校验结构化结果
  • 决定 pending_sample / pending_review / empty
  • 提供 AW 任务、回写与分享上下文 API
  • 默认全库 Search；可选属性过滤三段并更新索引
New老师 / Agent 判断
  • 读取 Fynn 发送的原文、来源和分类树
  • 最多生成一个二级分类候选
  • 返回结构化依据、说明与路由建议
  • 不直接改库、不建 AW 任务、不决定公开状态
AW：标注资料库整理
  • 消费 Fynn 已创建的确认与抽检任务
  • 支持确认、修改、暂不分类和已处理记录
  • 按 Fynn 契约提交结果，不直接修改底层数据
  • 负责分享卡片模板、渲染与端侧体验
接口交接 1：Fynn → Agent
输入信息
用户提交的语料内容与初始属性
触发方式
Fynn 检测需分类建议时主动触发
处理结果
Agent 返回一个候选、依据和路由建议
预期行为
Fynn 校验并决定抽检、人工确认或留空
接口交接 2：Fynn → AW
输入信息
Fynn 创建的确认或抽检任务
触发方式
pending_review 或抽中 pending_sample
处理结果
AW 提交确认、修改或暂不分类
预期行为
审核员收到通知，开始人工标注
接口交接 3：Fynn → Search
输入信息
Fynn 判定可公开的标准化词条
触发方式
内容发布、权利/属性/分类变更
处理结果
Search 更新索引与缓存
预期行为
默认不筛属性；显式参数才限定三段结果
