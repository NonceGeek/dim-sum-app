# S6\-活动小程序参赛问卷功能

# 需求背景

当前小程序已具备活动聚合页、活动详情页和参赛入口。用户可在活动详情页点击“参与投稿”时进入参赛流程。

现需补充参赛前问卷能力，目标有两点：

- 在用户正式参赛前完成必要信息登记。

- 收集有效联系方式，用于获奖通知、奖品发放及必要参赛事务联系。

根据微信小程序平台规范，用户未触发具体功能前，不应提前要求填写个人信息或强制授权；信息收集应在明确业务场景下进行，并向用户说明用途。

# 产品目标

1. 问卷仅在用户点击“我要投稿”后触发，不影响浏览路径。

2. 问卷采用底部弹窗形式，降低打断感。

3. 首次参赛时完成基础问卷与联系方式收集。

4. 已完成资料的用户后续参赛不重复填写。

5. 收集字段、使用目的与后台隐私保护指引保持一致。

# 适用范围

|适用于|- 活动详情页<br>- 参赛入口<br>- 投稿/报名前置流程|
|---|---|
|不适用于|- 首页首屏自动弹出<br>- 活动聚合页自动弹出<br>- 用户仅浏览、分享、查看详情时触发|

# 功能定义

1. 本功能属于“参赛前登记流程”，不是通用注册或资料完善流程。

2. 对外表达统一为：用户在参与活动前，补充少量必要信息，以便完成参赛登记、活动匹配及后续联系。避免背上过度收集用户信息的恶名。

3. 问卷数据看板：[S6\-问卷数据洞察看板](https://wcn3glqwz3m6.feishu.cn/docx/IFbSdKmYtoiBl9xUC0Bc9L8Vn3f?from=from_copylink)

# 触发规则

### 触发入口

活动详情页底部主按钮“我要投稿”。

### 触发时机

用户点击“我要投稿”后，系统校验当前用户是否已完成参赛资料登记：

- 未完成：弹出问卷弹窗。

- 已完成问卷但缺少联系方式：弹出联系方式补充弹窗。

- 资料完整：直接进入投稿/报名页。

### 禁止触发场景

以下场景不得自动弹出：

- 用户首次进入小程序时

- 用户从首页 Banner 进入活动页时

- 用户首次打开活动详情页时

- 用户仅浏览内容、分享活动时

📌以上场景不属于明确参赛动作，提前收集信息存在审核风险。

### 交互形式

采用底部弹窗（Bottom Sheet）形式触发。选择底部弹窗的原因：

- 与“我要投稿”按钮的操作链路一致。

- 不打断用户浏览活动内容。

- 相比整页跳转，填写压力更低。

- 便于分步展示说明、问卷和联系方式。

### 流程说明

- 用户进入活动详情页。

- 用户点击“我要投稿”。

- 系统判断资料状态。

- 若资料缺失，弹出底部弹窗。

- 用户完成填写后进入投稿/报名页。

- 用户再次参赛时，默认复用已填写信息。

### 禁用文案

以下表达不允许出现在正式页面中：

1. 籍贯• 户籍地

2. 老家详细地址

3. 完善资料

4. 解锁权益

5. 注册信息

原因：以上表述容易引发用户对身份识别或过度收集的敏感感知，不符合当前产品语境。

# 数据规则

|数据绑定|问卷结果与用户 UID 绑定，用于后续参赛流程复用。|
|---|---|
|复用规则|- 同一用户首次完成填写后，后续参赛默认不重复弹出完整问卷。<br>- 若手机号为空、失效或活动要求再次确认，则仅补充联系方式。|
|保存与删除|数据保存周期、删除规则和用户权利需在隐私保护指引中明确说明。|

# 合规要求

|后台配置|若前端涉及收集用户信息，必须在小程序管理后台配置《小程序用户隐私保护指引》，并确保以下内容一致：<br>- 收集字段<br>- 使用目的<br>- 使用场景<br>- 用户授权方式|
|---|---|
|前端要求|- 仅在点击“我要投稿”后触发。<br>- 收集前展示用途说明。<br>- 提供隐私保护指引入口。<br>- 提供继续与取消两个出口。<br>- 不默认同意。|
|风险点|以下情况需避免：<br>- 首屏强制弹窗收集信息。<br>- 用户未参赛前要求填写手机号。 <br>- 只有同意按钮，没有拒绝路径。<br>- 前端实际收集字段与后台声明不一致。 ￼|

# 验收标准

|交互验收|- 仅在点击“我也想参赛”后触发弹窗。<br>- 弹窗为底部上滑形式。<br>- 支持继续与取消。<br>- 填写完成后可正常进入投稿/报名页。|
|---|---|
|数据验收|- 问卷数据正确绑定 UID。<br>- 已填写状态可正确复用。<br>- 联系方式缺失时可单独补充。|
|合规验收|- 后台隐私保护指引与前端字段一致。 <br>- 手机号用途说明清晰。 <br>- 不存在默认同意、首屏拦截、强制授权等问题。|

# 结论

本方案计划将问卷定义为参赛前登记流程的一部分，在活动详情页点击“我要投稿”后，以底部弹窗触发，并采用“基础问卷 \+ 手机号”方式完成信息收集。
