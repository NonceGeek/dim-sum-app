# i18n 多语言设计方案

## 概述

为 dimsum-app 添加国际化支持，支持简体中文（zh-CN）和英文（en）。使用 `next-intl` 作为 i18n 框架，采用 URL 前缀路由策略，渐进式迁移。

## 决策记录

| 决策项 | 选择 | 理由 |
|--------|------|------|
| i18n 框架 | next-intl | 专为 App Router 设计，Server/Client Component 原生支持，轻量 |
| 路由策略 | URL 前缀 (`/zh-CN`, `/en`) | SEO 友好，可分享特定语言链接 |
| 默认语言 | zh-CN | 主要用户群在中国大陆 |
| 翻译范围 | 仅 UI 文案 | 粤语数据内容保持原样，不翻译 |
| 语言偏好存储 | next-intl 内置 NEXT_LOCALE cookie | 零额外代码，未来需要更多偏好时再引入 Zustand |
| 迁移策略 | 渐进式 | 先搭框架 + 公共组件，再逐页面迁移 |

## 目录结构

```
main/
├── messages/
│   ├── zh-CN.json              # 简体中文
│   └── en.json                 # 英文
├── i18n/
│   ├── routing.ts              # locale 列表 + 默认语言
│   └── request.ts              # 服务端 i18n 配置
├── app/
│   └── [locale]/               # 所有页面移入此处
│       ├── layout.tsx          # 根布局，接收 locale，设置 html lang
│       ├── (home)/
│       ├── (account)/
│       ├── admin/
│       └── api/                # API 路由不受 locale 影响
├── middleware.ts               # next-intl 路由 + next-auth 鉴权合并
└── next.config.ts              # 添加 next-intl 插件
```

## i18n 核心配置

### routing.ts

```ts
import { defineRouting } from 'next-intl/routing';

export const routing = defineRouting({
  locales: ['zh-CN', 'en'],
  defaultLocale: 'zh-CN',
});
```

### request.ts

```ts
import { getRequestConfig } from 'next-intl/server';
import { routing } from './routing';

export default getRequestConfig(async ({ requestLocale }) => {
  let locale = await requestLocale;
  if (!locale || !routing.locales.includes(locale as any)) {
    locale = routing.defaultLocale;
  }
  return {
    locale,
    messages: (await import(`../messages/${locale}.json`)).default,
  };
});
```

## Middleware 合并

将 next-intl locale 路由与 next-auth 鉴权合并到一个 middleware 中：

```
请求流程：
  /library → 重定向 /zh-CN/library（补全 locale）
  /zh-CN/library → 公共页面，只走 intl
  /zh-CN/account/profile → intl 处理 locale + auth 检查登录
  /zh-CN/api/marker → intl 跳过 + auth 检查角色
```

公共路由只经过 intl middleware，受保护路由先 intl 再 auth。

## 语言切换组件

在 header/nav 中添加 `LocaleSwitcher`：

```tsx
'use client';
import { useLocale } from 'next-intl';
import { useRouter, usePathname } from 'next-intl/navigation';

export function LocaleSwitcher() {
  const locale = useLocale();
  const router = useRouter();
  const pathname = usePathname();

  function switchLocale(newLocale: string) {
    router.replace(pathname, { locale: newLocale });
  }

  return (
    <button onClick={() => switchLocale(locale === 'zh-CN' ? 'en' : 'zh-CN')}>
      {locale === 'zh-CN' ? 'EN' : '中文'}
    </button>
  );
}
```

切换时 URL 变化（`/zh-CN/library` ↔ `/en/library`），next-intl 自动写入 NEXT_LOCALE cookie。

## 渐进式迁移顺序

### Phase 1：基础框架搭建
- 安装 next-intl
- 创建 i18n 配置文件（routing.ts, request.ts）
- 创建翻译文件（zh-CN.json, en.json）— 先只放 Common 和 Nav
- 页面移入 `app/[locale]/`
- 修改 layout.tsx 支持动态 locale
- 合并 middleware
- 更新 next.config.ts

### Phase 2：公共组件迁移
- 导航栏（header, floating-nav, menu-config）
- 语言切换组件
- 登录/角色选择对话框
- 通用按钮和提示文案

### Phase 3：逐页面迁移
- 首页（Home）
- 语料库（Library）
- 应用商店（AppStore）
- 个人资料（Profile）
- 数据标注（DataAnnotation）
- 管理后台（Admin）

每个 phase 完成后项目都可正常运行，未迁移页面保持现状。
