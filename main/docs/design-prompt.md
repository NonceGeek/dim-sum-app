# DimSum AI Labs — UI 重新设计简报

## 概述

重新设计 **DimSum AI Labs** — 一个粤语学习与数据标注平台。需要两个核心页面：

1. **搜索主页** — Google 风格的极简居中搜索体验
2. **搜索结果页** — 专业、信息丰富的结果列表布局

整体感觉应该是**高级、精致、专业的** — 参考 Google Search + Notion + 现代词典应用的交汇点。干净、自信、排版考究。面向语言爱好者和研究人员。

---

## 页面一：搜索主页

### 灵感参考
Google 搜索首页 — 大量留白，单一突出的搜索框，无干扰。搜索框是绝对主角。同时参考：Apple Dictionary、Notion 空状态页、Arc Browser 新标签页。

### 布局
- **水平垂直居中**对齐
- 顶部：DimSum logo（小巧精致）+ 品牌文字
- 中心：大型突出的搜索输入框，聚焦时带品牌蓝色微光
- 占位文本："搜索粤语词汇、语料库..."
- 搜索框下方：热门搜索词作为可点击的 pill/chip 标签（如：落花流水、唔听、行）— 使用 outline 风格的 badge
- 再下方：分类快捷入口卡片 — "语料库"、"标注"、"应用"、"文档" — 极简图标 + 文字，4 列网格
- 背景：
  - 亮色模式：干净的白色 `#ffffff`，带非常微妙的暖中性色调
  - 暗色模式：深海军蓝黑色，带微妙的蓝色底调（`oklch(0.13 0.02 256)`）
- 可选：搜索框背后添加非常微妙的抽象渐变或纹理元素 — 克制、不分散注意力

### 搜索框交互行为
- 大尺寸输入框，圆角 `12px`，突出但不笨重
- 聚焦时：使用品牌蓝 `#007fff` 的 `0.2` 透明度扩散光环
- 输入触发 500ms 防抖搜索
- 搜索结果以内联下拉形式出现，按分类展示：
  - 词汇（含粤拼读音 + 释义）
  - 语料条目（含来源 + 预览）
  - 书籍（含封面缩略图 + 作者）
- 键盘导航：上下箭头选择，Enter 确认，Escape 关闭

### 整体感受
- 宽敞、沉静、有学术气息
- 搜索框像是一个探索的邀请 — 大、易用、温暖地微微发光
- 没有视觉噪音 — 让排版和间距来做表达
- 感觉像打开了一本设计精美的词典

## 页面二：搜索结果页

### 灵感参考
Google 搜索结果 — 干净的左对齐结果，清晰的视觉层级。同时参考：Jisho.org（日语词典）、MDBG 中文词典、Notion 搜索结果。

### 布局
- **顶部导航栏**：紧凑型，内嵌搜索框（主页搜索框的缩小版），logo 在左侧
- **结果区域**：左对齐，最大宽度 ~800px，行距充裕
- **左侧边栏**（可选，仅桌面端）：筛选面板 — 按语料库、分类、来源、日期筛选
- 每个结果卡片包含：
  - 类型徽章（"词汇"、"语料"、"书籍"）— 使用语义色
  - 主要内容：大字展示词汇/短语 + 粤拼注音
  - 释义/含义使用正文字体
  - 来源/语料引用使用弱化文字
  - 例句中高亮匹配词
  - 微妙的 hover 效果：背景轻微抬升 + 阴影

### 结果卡片变体

1. **词汇/短语结果**
   - 大字：粤语词汇（大号加粗）
   - 粤拼读音（弱化色，在下方）
   - 释义/定义
   - 来自语料库的用法示例

2. **语料条目结果**
   - 来源徽章（书名/语料库名）
   - 文本摘录，搜索词用品牌蓝高亮
   - 元数据：作者、日期、分类

3. **书籍/资源结果**
   - 缩略图 + 书名 + 作者
   - 描述预览
   - 标签（badge chip 形式）
   - 互动数据（点赞、评论）— 弱化展示

### 整体感受
- 数据导向但不令人压迫
- 学术感但平易近人 — 像一个设计精良的研究工具
- 通过字重、字号、颜色透明度建立清晰的视觉层级
- 结果之间有充裕的留白 — 每张卡片都在"呼吸"

## 设计系统约束 — 不可更改

### 品牌色（Azure Blue — 单一主色族，50-950 色阶）

| 色阶 | Hex 值 | 用途 |
|------|--------|------|
| 50 | `#f1f6fc` | 最浅背景色调 |
| 100 | `#dbe9fc` | hover 状态、微妙填充 |
| 200 | `#b2d7ff` | 浅色强调背景 |
| 300 | `#80c0ff` | 次要高亮 |
| 400 | `#5aa8ff` | active 状态 |
| 500 | `#3193ff` | focus ring、链接 |
| **600** | **`#007fff`** | **主色 — 按钮、CTA、关键强调** |
| 700 | `#005fc6` | 主色 hover |
| 800 | `#004591` | 主色 active |
| 900 | `#052f61` | 暗色模式主色文字 |
| 950 | `#051f3f` | 最深品牌色调 |

| Token | OKLCH 值 | 近似 Hex | 用途 |
|-------|----------|----------|------|
| neutral-0 | `oklch(1.00 0.000 256)` | `#ffffff` | 白色背景 |
| neutral-50 | `oklch(0.98 0.003 256)` | `~#fafafa` | 微妙背景 |
| neutral-100 | `oklch(0.94 0.005 256)` | `~#eeeeee` | 卡片背景 |
| neutral-200 | `oklch(0.88 0.005 256)` | `~#d9d9d9` | 边框、输入框 |
| neutral-300 | `oklch(0.80 0.005 256)` | `~#c0c0c0` | 禁用文字 |
| neutral-400 | `oklch(0.68 0.005 256)` | `~#999999` | 占位符文字 |
| neutral-500 | `oklch(0.58 0.005 256)` | `~#777777` | 弱化文字 |
| neutral-600 | `oklch(0.48 0.005 256)` | `~#555555` | 次要文字 |
| neutral-700 | `oklch(0.38 0.005 256)` | `~#3a3a3a` | 正文（暗色） |
| neutral-800 | `oklch(0.28 0.005 256)` | `~#282828` | 标题文字 |
| neutral-900 | `oklch(0.22 0.005 256)` | `~#1e1e1e` | 主要文字 |
| neutral-950 | `oklch(0.15 0.005 256)` | `~#141414` | 近黑色 |

### 功能/语义色（基于 OKLCH）

| 角色 | OKLCH 色相 | 用途 |
|------|-----------|------|
| **危险/红色** | hue 25 | 错误状态、删除操作 |
| **成功/绿色** | hue 155 | 成功状态、确认 |
| **警告/琥珀色** | hue 85 | 警告状态、提醒 |
| **信息/蓝色** | hue 240 | 信息提示 |

### 暗色模式色板

| Token | OKLCH 值 | 用途 |
|-------|----------|------|
| dark-bg | `oklch(0.13 0.02 256)` | 页面背景 |
| dark-surface | `oklch(0.18 0.02 256)` | 卡片/表面背景 |
| dark-border | `oklch(0.25 0.02 256)` | 边框颜色 |

### 排版

| 角色 | 字体 | 说明 |
|------|------|------|
| 正文 & 标题 | **Inter** | 字重：400、500、600、700，来自 Google Fonts |
| 等宽字体 | **Geist Mono** | 用于代码、ID、技术数据 |


### 组件库
- 基于 **shadcn/ui**（New York 风格）+ **Radix UI** 原语
- 图标：**Lucide React**
- 动画：**motion**（Framer Motion）
- 图表：**Recharts**
- 通知：**Sonner**
- 按钮变体：default、destructive、outline、secondary、ghost、link

## 技术上下文

- **技术栈**：Next.js 16 (App Router) + React 19 + TypeScript + Tailwind CSS v4
- **数据类型**：粤语语料 — 词汇、短语、书籍、标注数据
- **国际化**：简体中文（zh-CN）为默认，英文（en）为辅
- **响应式**：移动端优先（375px+），桌面端最大宽度 1440px
- **主题**：亮色模式为默认，暗色模式支持。两者都需要精致好看。
- **认证**：微信 OAuth + 邮箱/短信登录（认证界面需美观呈现）

## 需要优化的方面

✅ 信息层级 — 通过字号、字重、透明度引导视线
✅ 间距与呼吸感 — 充裕且有目的性的留白
✅ 搜索体验 — 让搜索成为核心，快速且令人愉悦
✅ 排版 — 中日韩 + 拉丁文混排应该感觉和谐
✅ 卡片布局 — 干净、易扫视、有学术精致感
✅ hover/focus 状态 — 微妙、精致的微交互
✅ 空状态 — 美观、鼓励性的，而非空白
✅ 亮色和暗色模式 — 同样精致

## 不可更改的内容

🚫 品牌色板 — 必须使用上述精确色值（Azure Blue `#007fff` 为主色）
🚫 字体 — 保持 Inter（正文/标题）、Geist Mono（代码）
🚫 图标库 — 保持 Lucide React
🚫 组件原语 — 保持 shadcn/ui（New York 风格）模式
🚫 中性色板 — 保持基于 OKLCH 的中性色，hue 256
